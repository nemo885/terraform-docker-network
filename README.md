# 🚀 Multi-Tier Docker Infrastructure with OpenTofu

Этот проект представляет собой трёхуровневую архитектуру приложений (Proxy -> App -> DB), развёрнутую в Docker с помощью **OpenTofu** (Terraform). Управление сетью построено на динамическом субтитровании (`cidrsubnet`) и статической привязке IP-адресов через `cidrhost`.

---

## 🏗 Архитектура и Сетевая Безопасность

Проект использует три изолированные сети, созданные из единого базового блока `/16`:
1. **`frontend_net`** (`10.0.0.0/24`) — публичная сеть для связи пользователя с прокси.
2. **`backend_net`** (`10.0.1.0/26`) — внутренняя сеть для бэкенд-сервисов.
3. **`db_net`** (`10.0.1.64/28`, `internal = true`) — полностью изолированная сеть для базы данных (без выхода в интернет).

### Контейнеры:
* **`proxy`** (`nginx:alpine`) — подключен к `frontend_net`, пробрасывает порт `8080:80` наружу.
* **`app`** (`alpine`) — «мостик», подключен ко **всем трём сетям** (`frontend`, `backend`, `db`), обеспечивая безопасный поток запросов от Proxy к Базе данных.
* **`db`** (`redis:alpine`) — подключен только к изолированной `db_net` и защищен от прямого доступа извне.
